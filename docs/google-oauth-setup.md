# 구글 드라이브 연결을 위한 OAuth 클라이언트 만들기

마음장부는 손님 영상을 **주최자 본인의 구글 드라이브**에 저장합니다. 앱 운영자의 서버에는 영상 파일이 남지 않고, 구글 인증만 중계합니다.

아래는 한 번만 하면 되는 설정입니다. 웹 애플리케이션 클라이언트여야 하며, 범위는 드라이브 전체 접근이 아니라 `drive.file` 만 사용합니다.

## 1. 구글 클라우드 프로젝트

1. [Google Cloud Console](https://console.cloud.google.com/)에 구글 계정으로 들어갑니다.
2. 상단에서 **프로젝트 만들기**를 누르고 이름 예: `마음장부` 로 만듭니다.
3. 왼쪽 메뉴 **API 및 서비스 → 라이브러리**에서 **Google Drive API**를 찾아 사용 설정합니다.

## 2. OAuth 동의 화면

1. **API 및 서비스 → OAuth 동의 화면**으로 갑니다.
2. User Type은 처음에는 **외부(External)** 로 두고, 게시 전까지는 테스트 상태여도 됩니다.
3. 앱 이름: `마음장부`
4. 사용자 지원 이메일, 개발자 연락처 이메일을 본인 주소로 넣습니다.
5. 앱 로고는 나중에 넣어도 됩니다.
6. 범위(Scope)에서 직접 추가:
   - `https://www.googleapis.com/auth/drive.file`
   - (동의 화면에서 요청하는 범위는 이것만이어야 합니다. `drive` 또는 `drive.readonly` 는 넣지 마세요.)
7. **테스트 사용자**에, 실제로 연결해 볼 구글 계정(주최자 계정)을 추가합니다. 검증 전에는 이 계정만 연결할 수 있습니다.
8. 개인정보 처리방침 URL:
   - `https://eunyulchoe-cyber.github.io/chukuigeum-log/#/privacy`

## 3. OAuth 클라이언트(웹 애플리케이션)

1. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
2. 애플리케이션 유형: **웹 애플리케이션**
3. 이름: `마음장부 웹`
4. **승인된 자바스크립트 원본**에 정확히 다음을 넣습니다. 경로(`/chukuigeum-log/`)는 넣지 않습니다.
   - `https://eunyulchoe-cyber.github.io`
   - 로컬 확인용(선택): `http://localhost:5173`, `http://127.0.0.1:8787`
5. **승인된 리디렉션 URI**에 아래 주소를 **한 글자도 바꾸지 말고** 넣습니다.
   - `https://foimbsbpgvcftjxkxiur.supabase.co/functions/v1/google-oauth-callback`
6. 만들기가 끝나면 **클라이언트 ID**와 **클라이언트 보안 비밀**이 나옵니다. 보안 비밀은 이 화면을 벗어나면 다시 볼 수 없으니 안전한 곳에 복사해 둡니다.

## 4. 앱 운영자에게 전달할 값

다음 두 값을 운영자(이 앱을 배포하는 사람)에게만 전달합니다. 채팅이나 공개 저장소에 올리지 마세요.

- `GOOGLE_CLIENT_ID`
- `GOOGLE_CLIENT_SECRET`

운영자는 Supabase 프로젝트 `chukuigeum-log`(서울, `foimbsbpgvcftjxkxiur`)의 Edge Function 비밀로 이 값을 저장합니다. 저장이 끝나면 관리자 화면의 **구글 드라이브 연결** 버튼이 동작합니다.

## 5. 출시 전 구글 검증

테스트 사용자만 쓰는 동안에는 검증 없이 쓸 수 있습니다. 불특정 주최자가 각자 구글 계정을 연결하도록 **공개 출시**하려면 구글이 `drive.file` 범위를 **민감(Sensitive)** 범위로 보므로 앱 검증이 필요합니다.

준비할 것:

- 위에서 만든 개인정보 처리방침 URL (`#/privacy`)
- 앱이 이 권한을 쓰는 이유를 설명하는 영상: 주최자가 연결하고, 손님이 QR로 영상을 남기며, 파일이 주최자 드라이브의 앱 폴더에만 생기는 과정
- 홈페이지/앱 URL: `https://eunyulchoe-cyber.github.io/chukuigeum-log/`
- 브랜드, 로고, 지원 이메일
- 제한된 범위(`drive` 전체)는 쓰지 않으므로, `drive.file` 검증 절차만 따르면 됩니다. 검토에는 며칠에서 수주가 걸릴 수 있습니다.

검증이 끝나기 전에는 동의 화면이 “테스트”로 남고, 테스트 사용자로 등록된 구글 계정만 연결할 수 있습니다.
